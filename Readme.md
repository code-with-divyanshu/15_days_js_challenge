# 15 Days JavaScript Challenge

A practical JavaScript learning challenge based on the Chai aur Code course by Hitesh Choudhary. Each day focuses on a small set of JavaScript concepts and exercises that can be solved, tested, and reviewed independently.

## What this repository covers

The repository currently contains the first day's two chapters:

| Day | Chapter        | Concepts                                                                     |
| --- | -------------- | ---------------------------------------------------------------------------- |
| 01  | Hello, Console | `console.log`, `console.warn`, `console.table`, `console.count`, and timers  |
| 01  | Variables      | `let`, `const`, `var`, scope, mutation, hoisting, and the temporal dead zone |

More chapters and days can be added as the challenge progresses.

## Repository structure

```text
15_days_js_challenge/
├── Day_01/
│   ├── 01_hello_console/
│   │   ├── Readme.md
│   │   └── script.js
│   └── 02_variables/
│       ├── Readme.md
│       └── script.js
└── Readme.md
```

Each day contains:

- A README for each chapter's tasks, requirements, examples, and edge cases
- A `script.js` file containing the chapter's functions and exported answers

## How to use

1. Open a chapter folder, such as [`Day_01/01_hello_console`](./Day_01/01_hello_console).
2. Read its [`Readme.md`](./Day_01/01_hello_console/Readme.md) to understand the tasks.
3. Review or implement the functions in [`script.js`](./Day_01/01_hello_console/script.js).
4. Run the file with a JavaScript environment that supports ES modules, or use the course's exercise checker when available.
5. Compare the output and behavior with the requirements in the chapter README.

> The exercise files use `export` statements. Configure your JavaScript environment for ES modules before running them directly with Node.js.

## Learning goals

- Build a consistent daily JavaScript practice habit
- Understand JavaScript syntax through small, focused problems
- Learn how scope, variables, and hoisting affect program behavior
- Practice writing functions with precise inputs, outputs, and side effects
- Use the browser or Node.js console as a debugging and learning tool
