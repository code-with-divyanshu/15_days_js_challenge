# 15 Days JavaScript Challenge

A practical JavaScript learning challenge based on the Chai aur Code course by Hitesh Choudhary. Each chapter focuses on a small set of JavaScript concepts and exercises that can be solved, tested, and reviewed independently.

## What this repository covers

The repository currently contains two chapters:

| Chapter | Topic                    | Concepts                                                                       |
| ------- | ------------------------ | ------------------------------------------------------------------------------ |
| 01      | Hello, Console           | `console.log`, `console.warn`, `console.table`, `console.count`, and timers    |
| 02      | Variables                | `let`, `const`, `var`, scope, mutation, hoisting, and the temporal dead zone   |
| 03      | Data Types               | `typeof`, `null`, arrays, objects, deep copy,shallow copy, and equality checks |
| 04      | Numbers & Math           | `Math` methods, artithmetic, floating-point operations, and parsing            |
| 05      | Strings                  | `string` , string methods, and string manipulation                             |
| 06      | Template Literals        | `template` literals, string interpolation, and multiline strings               |
| 07      | Type Coercion            | `type coercion`, `==` vs `===`, and type conversion                            |
| 08      | Truthy and Falsy         | `truthy` and `falsy` values, boolean conversion, and conditional checks        |
| 09      | Null, Undefined, and NaN | `null`, `undefined`, `NaN`, and handling missing or invalid values             |

More chapters can be added as the challenge progresses.

Each chapter contains:

- A README for each chapter's tasks, requirements, examples, and edge cases

## How to use

1. Open a chapter folder, such as [`Day_01_hello_console`](./Day_01_hello_console).
2. Read its [`Readme.md`](./Day_01_hello_console/Readme.md) to understand the tasks.
3. Review or implement the functions in [`script.js`](./Day_01_hello_console/script.js).
4. Run the file with a JavaScript environment that supports ES modules, or use the course's exercise checker when available.
5. Compare the output and behavior with the requirements in the chapter README.

> The exercise files use `export` statements. Configure your JavaScript environment for ES modules before running them directly with Node.js.

## Learning goals

- Build a consistent daily JavaScript practice habit
- Understand JavaScript syntax through small, focused problems
- Learn how scope, variables, and hoisting affect program behavior
- Practice writing functions with precise inputs, outputs, and side effects
- Use the browser or Node.js console as a debugging and learning tool
